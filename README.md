# Veltrex

A simple-to-use MES (Manufacturing Execution System) style CNC operations management platform.

---

## Getting Started

Before starting, ensure you have ran `pnpm install` in the backend directory.

### Backend (`/veltrex-backend`)
NestJS + TypeScript

| Command | Description |
| :--- | :--- |
| `pnpm start` | Start the server |
| `pnpm start:dev` | Start in development mode (watch mode) |
| `pnpm build` | Build for production |
| `pnpm lint` | Run ESLint check and fix issues |
| `pnpm format` | Format code with Prettier |
| `pnpm start:prod` | Run the compiled production build |

---

### Tech Stack
- NestJS
- TypeScript
- PostgreSQL
- Prisma
- JWT
- Bcrypt
